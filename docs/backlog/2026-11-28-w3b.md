# Backlog 2026-11-28 (card W-3b: approvals of agents' publishes)

`W3B-Dn` (provisional decisions, design 18.9) and `W3B-n` (open items); the integrator may

| W3B-D1 | decision (provisional) | The 15 minutes of use count from `decided_at`: an approval moves `expires_at` to `decided_at + 15 min`, and the use also checks `decided_at` itself. A pending request expires `APPROVAL_HOURS` (24 h) after it was made. A pending or approved row past `expires_at` reads as `expired` **on read** (`approvals::status_at`, the list's status filter, the long poll); nothing writes `expired` and there is no sweeper step (as A-2). | `apps/approvals.rs` `status_at`, `check_use`, `decided`; tests `only_an_approved_unused_approval_within_15_minutes_is_used`, `a_pending_request_past_its_time_is_expired` | S | **panel**: confirm. |
| W3B-D2 | decision (provisional) | "The agent that asked" is the same agent ID and the same `on_behalf_of` user (the whole actor pair); any API key of that agent counts. | W3B-D3 | decision (provisional) | The approval is taken (`used`, `used_at`) **before** the release, in one store statement that checks approved, unused, the window, the actor pair, the app and the deployment again (two publishes with one approval: exactly one gets it). A release that fails after the take leaves the approval used; the agent asks again.
