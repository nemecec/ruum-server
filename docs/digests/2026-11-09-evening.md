## What changed on `main`

Four branches were rebased onto `main`, checked on the build server, pushed and checked in
GitHub CI, then fast-forwarded, in this order (`be7b572..4b15efc`, 7 commits, plus this
documentation commit). The history is linear: there is no merge commit and no co-author line.

- **The C-8 race is fixed** (`w/c8-race`, next card 1, backlog T-13). Right after an upload,
  the versions panel could mark the old version "Current" for a moment, and the C-8 browser
  test failed about once per CI run. The panel now reads the file's head together with the
  versions. A new flow test holds the reload and fails on the old code.
- **Each agent gets its own data cluster** (`f/pgdata-per-agent`, next card 2, backlog B-2).
  Every build server run of a current tree starts `pgdata-<key>` from the tree's own set-up, so
  a branch that changes the data cluster tests its own set-up, and agents never share databases.
  `--stop` removes it. Cost: about 4 s on the first run of a key. This integration used it for
  all its checks.
- **Long names in the column classes** (`f/k1c2-errors`, next card 3, review K-1 C-2). A
  SQLite name over 63 characters no longer stops the catalog sync on Postgres: it gets no class
  row and counts as personal (fail closed).
- **Shared step 2 error codes and a catalog rule** (`f/k1c2-errors`, next card 4, backlog P-3
  and S-12). The nine step 2 error codes of the contract are in the server's one error list,
  with `sqlstate` and `Retry-After`, so cards Q-2, A-2 and D-2 use them. New query rule 10: no
  write to and no schema change of the system catalog (for example `UPDATE pg_settings`), also
  inside `WITH` and `EXPLAIN`. One additive contract change (the rule in the `queryDatabase`
  text). Two bugs found on the way are fixed: a sort order that differed between the two class
  stores, and a data-modifying `WITH` that counted as a read.
- **The brand directions** (`w/brand-directions`, docs only). Three directions with palettes,
  type, icons, wordmark and mock screens in light and dark, all 252 contrast pairs checked:
  `docs/ux/brand/directions.html`. You already chose **Graphite** (decision 0005 B-5) and design
  12.6 (theme packages); the page is now on `main` as the record of that choice.

At the integration, `main` moved: the voice panel integration landed three commits during
this run. The stack was rebased a second time and pushed under new names (`-2`); its Rust code
did not change between the two rebases, and the browser tests ran again on each tip.
