  - `re-review-p2.md` **accepted** the P-2 fix (a `purged` delivery is retried until it
    succeeds). Its hostile tests found an older path: in Postgres, a payload that does not read
    still ends a `purged` delivery (F-1). F-1 was asked for "before D-1 starts the worker". D-1
    now starts the worker, and F-1 is not fixed yet. Only the platform writes the payload, so a

  - `re-review-e2.md` **was not complete**. It did not accept or reject the B-1 fix. Its open

    a tenant operator could run with `ruum_dbhost`'s rights, which reach the roles of every
    database. Now every `ruum_dbhost` session searches only `pg_catalog`. A hostile test and a
    mutation cover this. **No reviewer has checked this fix.**
