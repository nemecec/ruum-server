  `docs/STEP3.md` "The sandbox supervisor", decision 0006 I, provisional). A small static binary
  (`ruum-supervisor`, new workspace member) runs as PID 1 in each sandbox, fetches the run's
  values once (Docker: stdin; Kubernetes: `POST /v1/launch` with the pod's projected token,

  budget (64 MiB, 16 MiB per tenant) in both drivers (S-91). Staging: the charts and scripts for

  the lock). CI file: one line (the musl target for the supervisor's tests, named by the card).
