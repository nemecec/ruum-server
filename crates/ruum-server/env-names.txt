# Every environment variable that ruum-server reads (with the crates it links: ruum-core,
# ruum-api, ruum-mcp, ruum-webdav, ruum-dbengine). One name and one class per line:
#
#   required  a production deploy sets it (staging too). The server starts without most of them,
#             but then it falls back to laptop defaults or in-memory parts.
#   optional  the default fits, or the feature is off without it.
#   test      read only by tests. A deploy never sets it.
#
# deploy/staging/tests/server-env.sh checks this list both ways against the code (string
# literals in crates/*/src, without ruum-cli and ruum-testkit), and checks the rendered Helm chart
# with the keys of the Secret ruum/ruum-server-env (deploy/staging/k8s/apply.sh) against it.
# A literal "S3_<X>" counts as RUUM_S3_<X> (blobs/object.rs adds the prefix). The unprefixed
# laptop fallbacks (S3_*, SPICEDB_PRESHARED_KEY) are not listed.
